# WORK-LAB · L9 Interactive Demo

Open `interactive-demo.html` directly in a modern browser.

## Included interactions
- Workflow filtering
- Draggable workflow nodes with localStorage
- Approval modal
- Audit log
- Command palette
- Drawer + toast

## Storage
This demo uses browser `localStorage` for lightweight persistence.

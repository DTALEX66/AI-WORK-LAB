# 四、最关键的规则：课程内保留，知识库中复用

你现在不要把所有知识卡都只扔在课程文件夹里。否则以后同一个知识点会在 10 门课程里重复出现。

建议规则：

```text
课程包 = 保存这门课的上下文
知识原子库 = 保存可复用知识
复习系统 = 保存记忆和训练
项目行动库 = 保存能落地执行的东西
```

也就是说：

```text
课程中的 K001_提示词工程.md
```

可以同时被链接到：

```text
20_知识原子库/22_方法卡/提示词工程.md
40_项目行动库/43_提示词资产/提示词工程实战模板.md
30_复习系统/31_主动回忆/提示词工程复习卡.md
```

但不要复制太多份。最好是：

**课程内放“课程上下文版”，知识原子库放“最终沉淀版”。**

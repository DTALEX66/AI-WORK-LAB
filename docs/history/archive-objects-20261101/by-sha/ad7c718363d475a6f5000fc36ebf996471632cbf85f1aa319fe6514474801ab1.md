# 1. Open-AI-Design-Agent：目前搜到最像 DESIGN-LAB“AI 设计 Agent 层”的

urlOpen-AI-Design-Agent GitHubturn0search1

这个项目直接把自己定位成：

> Open-source AI design agent / Lovart alternative

它不是单纯文生图，而是：

**Brief → Agent Planning → 选择模型 → 生成不同资产 → 保持品牌一致性 → 组合交付**

支持的东西包括：

- 海报
- Social Media
- Brand Kit
- 广告创意
- Logo
- 产品 Mockup
- Motion Ads
- Video
- Vectorize
- Remove Background
- Upscale
- Workflow Studio

而且它已经在做一个 DESIGN-LAB 很需要的概念：

**根据设计任务自动选择不同模型。**

例如：

```text
用户 Brief
 ↓
Design Agent
 ↓
任务拆解
 ↓
Poster → Ideogram
Product → Nano Banana
Vector → Recraft
Video → Kling / Veo / Sora
 ↓
Brand Consistency
 ↓
Asset Assembly
```

它宣称可以编排 200+ 图像/视频模型，并且 Agent loop 可以检查、修改和扩展。citeturn0search1

### 对 DESIGN-LAB 的意义

这个项目不要简单理解成“竞争项目”。

它实际上很适合拿来研究：

**Design Agent Orchestration Layer**

特别是：

`Brief Parser / Planner / Asset Dependency / Model Router / Brand Conditioning / Multi-asset Generation / Assembly`

这些模块。

但它仍然比 DESIGN-LAB 的定位窄很多。

它主要还是：

> **Generative Creative Agent**

而 DESIGN-LAB 要做的是：

> **Professional Design Intelligence + Creative Toolchain + Production**

这是两个层次。

# 2. Penpot：非常重要

urlPenpot GitHubturn1search3

**Design + Code + Design System + API + Plugin + MCP + AI**

- SVG
- CSS
- HTML
- JSON
- Design Tokens

- Variants
- Plugin System
- API
- MCP

尤其关键：

Penpot 已经明确把 **AI workflow** 纳入平台架构。citeturn1search3

这意味着：

```text
DESIGN-LAB Agent
       ↓
     MCP
       ↓

       ↓
```

是完全合理的路线。

## 我建议下一轮不要停在这 10 个

这次只是第一轮，我已经发现搜索方向比“AI Design Agent”本身大很多。

下一轮我建议直接给 DESIGN-LAB 建一个 **Open Source Landscape**，继续全网/GitHub 深挖 **50～100 个项目**，按下面这些类别搜：

**① AI Design Agent**：Lovart/Open Lovart 类；**② Infinite Canvas**：Flora/Weavy 类；**③ Generative Design**：图像/视频/3D；**④ Graphic Design**：海报/品牌/包装/电商；**⑤ UI/UX**：Figma/Penpot/Design-to-Code；**⑥ Adobe Automation**：Photoshop/Illustrator/InDesign/Premiere/AE；**⑦ 3D**：Blender/CAD/Spatial；**⑧ ComfyUI生态**；**⑨ Design MCP / Creative MCP**；**⑩ Design Agent Skills**；**⑪ Design System / Tokens**；**⑫ Visual QA / Design Critique**；**⑬ Production / Preflight / PDF / Print**；**⑭ Asset Management / Brand Kit**；**⑮ Motion / Video / Audio**；**⑯ Game Design**。

然后不只是“列 GitHub”，而是给每个项目打：

**相关度 / 成熟度 / Stars / 活跃度 / License / 可复用模块 / 可直接接入 / 可 Fork / 只参考 / 与 DESIGN-LAB 重叠能力 / DESIGN-LAB 当前缺失能力**。

最终会得到一张真正有用的：

> **DESIGN-LAB 开源技术雷达 + 候选组件池 + 架构补强清单**

这个比单独找几个“类似项目”价值高很多。memcite

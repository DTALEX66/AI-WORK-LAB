# 十二、仓库体积瘦身必须分两阶段，不能直接 filter-repo

### 第一阶段：不改 main 历史

```text

```

### 第二阶段：对象级 forensic

之后重新检查 repo size。

如果仍然几百 MB：

```bash
git rev-list --objects --all
git cat-file --batch-check
```

按 object size 找历史巨型 blob。

只有确认大对象仍在 main ancestry 时，才考虑：

```text

```


所以绝不能和普通开发混在一轮做。

## AI 到底可以操作到什么程度？

以 Photoshop 为例，不要做成：

```text
AI：
点击菜单
点击图层
鼠标移动
按 Ctrl+T
输入 50%
```

这是最差的一种方案。

应该做成：

```text
用户：
把当前文件所有产品图片宽度统一为 1600px，
保持比例，不修改文字图层，
背景统一 #F5F5F5，
产品居中，
保留原 PSD，
另外导出 WEBP。
```

AI理解之后转换成：

```text
getDocument()
getLayers()
identifyProductLayers()
resize()
align()
setBackground()
savePSD()
exportWebP()
```

然后 Photoshop UXP 执行。

这才是真正稳定的 **Agent → Adobe**。

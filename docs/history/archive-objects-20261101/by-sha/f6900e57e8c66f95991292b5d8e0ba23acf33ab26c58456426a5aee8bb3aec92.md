## 三、索引是不是该更新？该，而且有三个明确缺口

### 1. 模型目录索引，不等于可用模型索引

`R6-MODEL-LIBRARY-INVENTORY-20260919.json` 是目录盘点；`r6-capability-pool.json` 仍引用 `local-2026-09-05-historical`，不少条目的量化是 `runtime-default`，内存字段为空。R6 的 A11 也明确保留“执行程序、运行时回读、按角色基准测试未完成”的缺口。fileciteturn23file0L2-L2 fileciteturn8file0L2-L2 fileciteturn18file0L2-L2

建议在**现有能力池上补齐字段**，而不是再另建一套相互竞争的模型注册中心：

```text
模型标识／来源 revision
共享资源 ID／相对路径
格式／量化／文件或 manifest 摘要
推理引擎／实际版本
支持的角色与输入模态
最近探测时间／探测结果
实测 RAM、VRAM、首字延迟、吞吐
当前默认／固定回归基线／升级候选
对应测试收据／失败回退
```

状态至少要区分：**已发现、文件完整、服务可达、推理成功、管线通过、允许作为默认**。不能只有“已安装／未安装”。

### 2. 真实模型接入，仍有未闭合的部分

## 五、能否同时当项目底座和管线测试模型？能，应该这样共用

**共用同一份权重，但不共用一套可随时漂移的测试配置。**

我建议按下图组织；这是建议的接入方式，不是声称仓库已经实现：

```text
共享模型库：D:\All projects\Model library
                  │
          模型摘要＋运行时版本
                  │
             本地模型服务
          ┌───────┴────────┐
          │                │
   AAOS 应用运行配置    AAOS 管线测试配置
   当前已验收默认       固定基线＋升级候选
          │                │
   用户业务数据边界     ceshi 已授权测试样例
                      输出到项目 .project-local
```

这里最重要的是三个分离：

**权重与角色分离。**同一份 Qwen 权重可以承担 `text_chat`、`vision_understanding`、`pipeline_candidate` 等角色，不需要为“底座模型”和“测试模型”各下载一次。但语音转写、语义向量、重排是不同任务，不能因为有了一个多模态聊天模型就删掉 Whisper、SenseVoice 或专用检索模型。

**生产默认与回归基线分离。**旧 Qwen3 8B、Qwen2.5-VL 7B 先保留。测试记录绑定具体摘要、量化、模板、上下文和引擎版本；新模型赢得测试后才切换默认，旧基线仍可用于定位回归。不要用不断变化的 `latest` 代替固定测试身份。

**被测模型与裁判分离。**同一个模型可以参与测试，但不能仅靠它给自己的答案打分来证明升级成功。结构化输出用 schema 检验，引用用源文档锚点检验，转写用人工确认文本检验，复杂问答再辅以另一模型或人工复核。

在 8GB 显存下，我建议**生成模型串行占用 GPU，检索／重排先测 CPU 或分阶段调度**，不要让 AAOS、管线测试、ComfyUI 各自常驻一份大模型来抢显存。这是针对你硬件的资源调度建议，最终并发上限由实测决定。

## 六、我建议这轮真正执行的更新顺序

### 先补完整索引，不先下载

沿现有共享根检查 Ollama `manifests`、模型服务清单、版本与量化；核对 Whisper／Sherpa 的必要文件；只对本轮会用到的权重做完整性核验。Ollama 官方的模型列表接口会返回模型名称、摘要、大小和量化等信息，可作为库存登记的输入。citeturn232957view1

更新现有能力池及其数据契约，保留历史清单，不覆盖成“全部已验证”。同时修复共享资源根的 schema 表达；**不碰 ComfyUI 资产，不清理共享库，不启动或替换真实绿色版来做实验。**

### 再接通最小真实链路

优先完成：

> **资料输入 → 真实语义检索 → 必要时重排 → 本地模型回答 → 可核验引用／输出 → 重启读回。**

`hash-embedding` 和 `local-stub` 可以继续服务于确定性单元测试，但不应被当成真实语义能力的验收结果。更换 embedding 后，应建立独立的新向量索引并重新编码测试资料，不能只改模型名称、继续混用旧向量。

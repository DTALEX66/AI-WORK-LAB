# 01 / AAOS

## ARCHEAXIS  
## KNOWLEDGE OS

**KNOWLEDGE  
THAT COMPOUNDS.**

让知识不再随着一次对话结束而消失。

AAOS / ArcheAxis 是一个面向个人与 AI Agent 的知识操作系统。

它尝试把散落在对话、文档、研究、项目、代码和模型中的信息，转化为可以持续检索、理解、验证和再次调用的长期知识资产。

**A knowledge operating system built for humans and agents.**

一个同时服务人与 Agent 的知识操作系统。

它让过去发生过的研究、判断、文件、讨论与执行结果，能够重新成为下一次决策的上下文。

# 02 / WORK-LAB

## WORK-LAB  
## AGENT EXECUTION SYSTEM

**FROM INTENT  
TO EXECUTION.**

AI 不应该只给答案。

它应该能够完成工作。

WORK-LAB 是一个围绕多 Agent、任务编排、审批、工具调用和执行追踪构建的 AI 工作执行层。

它连接：

**规划 → Agent → 工具 → 审批 → 执行 → 结果**

把一次 Prompt 变成一个可以被观察、控制和重复执行的工作流程。

---

## PROJECT OVERVIEW

大模型已经很擅长告诉我们：

**“应该怎么做。”**

真正困难的是下一步。

谁去做？

调用什么工具？

什么时候需要人工确认？

任务失败以后发生什么？

不同 Agent 如何协作？

运行结果怎样重新进入知识系统？

WORK-LAB 从这里开始。

---

## THE QUESTION

**WHAT IF  
A PROMPT COULD  
BECOME A WORKFLOW?**

如果一次自然语言指令，可以自动展开成一套可控执行流程呢？

不是一个 Agent 解决所有问题。

而是让不同能力的模型、Agent 与原生软件进入同一个协作环境。

---

## THE SYSTEM

**PLAN**

理解目标并拆解任务。

**ROUTE**

选择合适的模型、Agent 与工具。

**EXECUTE**

调用真实环境完成工作。

**APPROVE**

高风险动作进入人工审批。

**OBSERVE**

记录状态、时间、Token、成本和错误。

**LEARN**

把运行结果重新交还给知识系统。

---

## CORE IDEA

WORK-LAB 并不追求完全无人化。

它关注的是：

**在自动化能力与人的最终控制权之间，建立清晰的边界。**

**12-column**

**32–48px**

# 二、从设计师角度：你的网站不应该“长得像作品集模板”

不是字体。

**它把作品浏览本身变成了体验。**

你的 DT ALEX STUDIOS 也应该有自己的“观看方式”。

# 三、真正值得从 Unseen 继承的只有 4 个东西

### 1. 第一屏的空间感

第一次打开网站，不马上出现：

“大家好，我是 Alex，一名……”

太普通了。

直接：

# DT ALEX STUDIOS

小字：

Graphic / Brand / 3D / Motion / Digital

然后屏幕里已经有作品。

用户移动鼠标，作品轻微产生视差。

拖拽，可以探索。

Hover，一张海报开始变化。

某个 Motion 自动播放。

某个 3D 项目轻微旋转。

某个网页项目出现 cursor interaction。

**你的介绍不是文字介绍出来的，而是作品自己介绍。**

---

### 2. 大图与留白

不要一屏塞 6 个项目。

你的优质作品应该敢于：

**一屏一个。**

甚至一件作品占 1.5 屏。

这样你的平面设计才真正有机会被认真看。

---

### 3. 项目之间的过渡

项目 A 结束后，不应该：

`← BACK`

然后回列表。

可以直接出现：

**NEXT**

下一张项目视觉从下面进入。

用户一直往下浏览。

非常顺。

---

### 4. Experiment 的自由度

这里可以完全放开。

因为它不是求职证明。

它是你的兴趣。

所以 Creative Coding、AI 图像、Shader、Vibe Coding、小工具、失败实验，都可以出现。

这会让整个网站有“人”的感觉。

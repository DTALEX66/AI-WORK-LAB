Gitee 这里确实不像 GitHub 那样明显显示**个人空间总容量 / 仓库占用大小**，很多用户都会找不到。

你可以几个方式查看：

---

## 方法1：查看单个仓库大小（网页端）

进入你的仓库：

```
仓库主页
→ 文件
→ 管理
→ 仓库设置
```

部分版本会显示：

- 仓库大小
- Git LFS 使用量
- 存储统计

但 Gitee 不同版本界面位置可能变化，有些个人仓库不会直接展示。

---

## 方法2：用 Git 命令查看（最准确）

克隆仓库：

```bash
git clone https://gitee.com/用户名/仓库名.git
```

进入：

```bash
cd 仓库名
```

查看 Git 历史大小：

```bash
git count-objects -vH
```

会看到：

例如：

```
size-pack: 850 MiB
size: 120 MiB
```

其中：

- size-pack = 历史压缩对象大小（主要占用）
- size = 松散对象大小

---

## 方法3：本地查看仓库实际大小

Windows：

右键仓库文件夹：

```
属性
```

但是注意：

```
.git
```

你的项目：

例如 AAOS：

```
AAOS
├── src
├── assets
├── models
├── docs
└── .git

```
.git

- 强烈建议 < 5GB


### 单文件

- 超过 **100MB**：
  - GitHub 不允许直接 push

需要：

```
Git LFS
```

免费1TB

这种额度。

> 代码仓库无限创建，但不要作为大文件存储。

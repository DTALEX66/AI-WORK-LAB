# 前端承接与状态规则｜R5
这是交接设计，须吸收到现有项目契约和组件；不是新的运行注册器或第二份知识真值。

## 固定部分与变化部分
固定：应用壳、五入口、当前对象身份、知识/来源固定版本、当前任务、草稿与返回位置。
变化：当前活动的渲染器、局部工具、参数编辑、产物与反馈。
按实际需求复用现有Tiptap、PDF.js、Dockview等已安装组件。名称为历史接线线索，具体版本与可用性由本地核验，不自动安装或升级。

## 学习活动的最小承接信息
沿现有Profile/Recipe/Event及课程对象，查缺补漏：
- 活动类型与定义版本；所属任务、目标和顺序/依赖。
- 输入的知识/原件/课程固定引用，材料权限范围。
- 当前草稿、活动参数/初始条件、呈现偏好及可恢复位置。
- 输出的笔记、回答、作品、实验记录或回忆事件引用。
- 能力与依赖资格、运行请求/attempt和返回到哪个任务。
这些是逻辑字段，不要求新建同名表，也不以一个任意JSON字段替代业务校验。

## 六个相互独立的状态轴
1. 设计覆盖：已映射/本批已画/尚未画，不等于已实现。
2. 实现证据：待核验/待开发/前端演示/待接入/已接入。
3. 依赖事实：已发现/已安装/已配置/可达，各自可未知。
4. 当前任务资格：主体、对象、用途、版本、预算、数据出境是否允许。
5. 单次执行：排队/运行/取消已请求/成功/失败/结果未知，按现有Core状态解释。
6. 内容与学习：内容核验、人的表现、AI评测/采用/使用效果分开。
缺证据显示未知；启动页面、读状态、恢复布局不能偷偷启动引擎或调用外部工具。

## 非执行预览
预览可切tab、改示例参数和打开说明，只写隔离的演示状态；不进真实知识结果、学习事件、评测、使用统计或成功回执。演示支持不等于生产执行资格。
本包图片均静态设计；本轮未提供可点击原型或真实存储测试。

## 退出、恢复和更新
面板关闭不等于任务取消。恢复只重建布局与对象引用；结果未知先查原请求，不换ID重跑。
正文与授权只存既有业务对象，布局不复制正文/凭据。旧版本、撤回资产及不可用依赖仍可查历史。
切呈现保留草稿与知识身份；任务型产物按所属活动独立保存。活动完成、作答提交、AI候选保存、资产采用都是明确动作。

## 能力详情
用途、所处环节、输入输出、实现证据、前提、候选接入方式、当前支持范围、难度、后续阶段、替代方法和重新启动条件。
用户日常面只显示相关信息，协议和工具权限放详情。MCP、插件、技能等标签不是授权开关；对方工具描述属于外部输入，不能覆盖用户权限。

## 尚需实现与核验
本轮只完成设计映射与代表画面。尚缺本地真实API绑定、可点击状态联调、各活动的保存/恢复和真实执行资格；不得将图片或CSV行数当产品验收。
优先用五个代表场景验证可扩展工作区；不要求先实现所有引擎。

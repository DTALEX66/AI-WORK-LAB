### 最简单的配置方法

先打开：

urlGoogle AI Studiohttps://aistudio.google.com/

登录你的 Google 账号，然后按这个路径：

**Dashboard → Projects**

这里分两种情况：

1. **已经有项目**
   - 直接选这个项目。
   - 如果项目没显示，点 **Import projects**
   - 把你 Google Cloud 里的项目导入 AI Studio。citeturn171243search0

2. **一个项目都没有 / 它一直让你去 Cloud 创建**
   - 创建一个新的 Google Cloud Project。
   - 名字随便，比如：

```text
Gemini-API-Free
```

   - 创建完成后回到 AI Studio：
   
```text
Dashboard
→ Projects
→ Import projects
→ 搜索 Gemini-API-Free
→ Import
```

这一步就是你之前一直看到的“**去 Cloud 创建项目**”的原因。它实际上只是给 Gemini API 找一个**额度、权限、API Key 的归属容器**，不等于收费。citeturn171243search0turn171243search1

---

然后进入：

**Dashboard → API Keys → Create API key**

选择刚才的：

```text
Gemini-API-Free
```

创建之后会得到一串 Key，例如：

```text
AIzaSyxxxxxxxxxxxxxxxxxxxxxxxx
```

**不要把真实 Key 发给我，也不要上传 GitHub。**

这里有一个非常重要的新变化：从 **2026 年 5 月 28 日**开始，AI Studio 新创建的 Key 默认已经是新的 **Auth Key**。而旧的 Standard API Key 在 **2026 年 9 月开始被 Gemini API 拒绝**。所以你现在最好**直接在 AI Studio 新建 Key**，不要照旧教程去 Google Cloud Credentials 创建老式 unrestricted key。citeturn171243search0

```text

```

```text
Google账号
↓
绑信用卡
↓
开 Cloud Billing
↓
才能用 Gemini
```

后者不是你目前用免费 API 的必要步骤。

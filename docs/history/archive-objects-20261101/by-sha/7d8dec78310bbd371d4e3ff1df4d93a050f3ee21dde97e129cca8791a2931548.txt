请为 DESIGN-LAB（设计实验室）开启第一阶段桌面端 UI 设计。

本提示词完整定义产品范围，但本轮实际只生成文末明确列出的四张核心画面。不要只做首页、海报或文字说明，也不要提前编写原型代码、宣称交互测试通过。

一、产品身份

DESIGN-LAB 是设计知识与提示词管理、创意方案和外部工具应用辅助软件。

它帮助用户：
整理需求与参考；
分析、拆解并重构创意；
查找和更新设计知识；
形成专业设计方向、脚本、分镜、声音说明和提示词；
根据所选软件、平台、模型与模式调整材料；
把可使用的材料交给外部工具实施。

用户可以采用、修改、试用或放弃方案。
当前不负责执行制作、交付成品或发布，不是第二套Agent、设计编辑器、剪辑软件或模型生成平台。
不内置可编辑3D场景、剪辑时间线、粒子仿真、节点工作流和音乐工作站。

界面面向普通创作者和需要设计帮助的产品负责人。用户不必懂模型参数和专业术语才能开始。
专业性体现在后台知识、方案内容和工具适配，前端保持轻量。

当前独立运行，不依赖AAOS或WORK-LAB启动。
AAOS知识互联、自动派发和软件自动操作属于未来，不设计当前连接红灯、同步按钮或自动执行入口。

二、完整能力范围：同一套界面承载

覆盖：
品牌与平面、UI/VI/UX、2D/3D、动效、粒子、视频、音乐、配音与音效。

来源可以是：
产品资料、广告需求、参考图、小说、漫画、短剧、漫剧、歌词、说唱、MV或用户原创内容。

分清：
小说、歌词是内容来源；
短剧、漫剧、MV是作品形式；
2D、3D、粒子是表现手法；
平台、软件、模型和外部Agent是实施选择。

这些维度可以组合，不为每个词增加一级菜单或独立工作台。
独立音频不强制添加画面；平面设计不强制填写镜头；3D方案不打开3D编辑器。

三个典型需求均需能容纳：
A. 从网上收集参考，分析拆解，再结合自己的想法重构设计。
B. 产品进入宣传期，准备共享品牌方向下的UI/UX、VI、宣传物料与影音方案。
C. 小说、漫画、广告、歌曲等内容转化为适合不同工具和模型的脚本、镜头、声音与提示材料。

三、三个主入口

主导航：
设计辅助 / 知识与提示词库 / 我的方案。
设置放底部。

设计辅助包含需求入口和方案工作页，不另加两个一级菜单。
参考分析、目标适配、知识详情、版本比较使用按需详情或抽屉。

工具与模型档案、方案助手服务、导入更新、数据备份、专业接口和标准接口放设置。
不加入WORK-LAB式项目监控、HUD、审批、运行指标和软件故障看板。

四、用户最短路径

说明想做什么 → 可选添加参考 → 得到可理解的设计方向 → 修改或选择 → 选外部目标 → 复制或导出材料。

不要求先建立复杂项目、配置所有模型或填写专业表单。
允许暂不确定工具，先得到中立方案，再适配具体目标。
允许直接浏览知识、编辑模板或复制已有材料，不强迫启动模型。

五、视觉基线

沿用DESIGN-LAB此前确定的浅色方向，本轮只出浅色主稿，不同时再做一整套深色主题。

气质像安静、精致的设计资料桌：清透、易读、留白有节制。
通过参考缩略图、排版和设计内容体现质感，不靠发光特效和巨大容器。

配色：
背景 #F4F6F8
正文表面 #FFFFFF
主要文字 #202630
次要文字 #5D6876
边线 #DFE4EA
唯一品牌强调色 #3F6C90

素材与方向示意可以有自己的色彩，应用外壳不随之变成彩虹渐变。
状态色少量使用并配文字，不能靠颜色单独表达含义。

少量玻璃感仅用于顶栏、侧栏和临时浮层。正文与编辑区域保持清晰实底。
不使用整屏模糊、AI发光球、科幻网格、装饰粒子、巨型欢迎语和营销Hero。

系统无衬线字体，优先Segoe UI和中文本地字体。
主要正文14–16px，辅助信息一般不低于12px，标题22–26px。
按钮圆角6–8px，内容表面10–12px，弹层16px左右。
减少卡片套卡片，知识列表不做厚重卡片墙。

Windows桌面，右上角窗口控制，Ctrl快捷键。
主画板1440×900，布局兼顾1280×800；不做移动端，不画macOS红黄绿按钮。
不以整张画板缩放代替窗口适配，不挤压长中文标题。

本轮不依赖远程图标字体。用可正常显示的SVG或设计工具原生图标。
不得出现folder_open、arrow_forward等图标代码文字。

六、四张核心画面

D01 设计辅助：从需求开始

这是默认首页。

首屏只突出：
带标签的需求输入；
添加参考；
想拿到什么；
一个主要操作。

需求示例：
“我有一款桌面笔记软件，希望整理品牌视觉方向，并准备一支15秒宣传片的脚本和提示材料。”

这是设计演示，不代表已经有真实附件或已经完成分析。

输出类型用紧凑选项：
品牌与平面 / UI与体验 / 视频与分镜 / 3D与动效 / 音频。
允许按需求组合，进一步的短剧、漫剧、粒子、音乐、配音、音效在相关类型中按需出现。

参考入口支持表达图片、资料、链接，以及按能力支持的音视频输入。
软件无法读取某类附件时，提供手动说明、关键帧或文字稿方式，不伪装已经理解。

平台与模型可以稍后选择，不默认展开高级参数。
主操作使用“整理需求”或“准备设计方向”，不要写“一键完成全套设计”。

下方可有少量最近方案文本行或简洁的“从参考开始”“整理产品宣传方案”等入口，不做大型统计卡或功能广告墙。

页面像一个清楚的工作入口，不是聊天气泡流，不添加AI人格、对话头像或复杂欢迎仪式。

D02 方案工作页：核心阅读与选择

沿用D01示例，展示一份“桌面笔记产品｜品牌与15秒宣传方向”。

主体是一份可阅读、可修改的方案。
通过少量上下文切换呈现：
设计方向 / 脚本与分镜 / 工具材料。
根据任务调整名称：纯音频可显示声音方案，平面任务不强制显示分镜。

本轮D02默认展示“设计方向”。
用两个克制的方向示意或A/B切换，帮助用户比较。
每个方向包含小型视觉示意、几项关键设计决定和一句适合原因。
示意可以是自绘几何、版式、色彩与材质组合，不冒充已生成成品。

不要只写“高级、科技、简约”等空泛形容词。
方案需要说明受众、表达重点、视觉层级、色彩与版式逻辑，以及应保留的品牌约束。
UI与体验方案还应体现用户任务、信息结构和关键交互建议，不能只给配色与漂亮截图，也不能用视觉方向代替可用性验证。

主体中展示一小段“其他输出如何沿用这个方向”的图文摘要：
品牌与UI表达如何统一；
宣传片如何延续视觉语言；
需要哪些外部材料。
不同时展开整本品牌手册、全分镜与全部提示词。

可用少量缩略图、色板、简短对比和静态分镜示意减轻阅读。
不做无限画布、可编辑节点图或剪辑时间线。
分镜是阅读与交接说明，不是可拖拽剪辑工具。

用户可以选择方向、修改局部、暂不采用、保存方案。
主要操作“准备工具材料”。
更改目标时保留原始创意，不要求重做整份需求。

头部简洁显示方案名、状态、修订和当前外部目标；目标可以为“稍后选择”。
专业依据与来源通过小型引用入口查看，不铺满版本、合同和审计字段。

D03 知识与提示词库

内容是产品核心之一，不能缩成只有收藏夹或一页只读资料。

顶部：
搜索、紧凑筛选、新增或导入入口。
主体采用内容清楚的列表或轻量两栏浏览。

可管理：
设计原则与规范；
提示词模板；
软件与模型使用指南；
制作方法与适配配方；
成功、失败与待验证案例。

品牌、UI、2D、3D、粒子、短视频、短剧、漫剧、音乐、配音、音效作为标签或筛选。
不要给每个标签建立一个模块。

每条默认只显示：
标题、一句用途、适用类别或目标、最近更新时间。
来源、修订、验证范围在详情中查阅。

允许搜索、收藏、新增、导入、编辑、引用到当前方案、复制和查看历史版本。
本轮是这些能力的UI设计，不代表后台已经全部实现。

“来源与更新”放在本库二级入口：
显示有变化的资料和受影响条目，用户按需比较。
新资料先成为待评估更新，不自动覆盖旧方案正在引用的版本。

开源项目、官方资料和实践案例可作为来源。
“已收录”“可参考”“已适配”“已试用”不能混成“已吸收”。
不把项目星数、热度或链接存在当成专业效果证明，不在普通界面放开源评分仪表盘。

D04 我的方案

采用最近文档式列表，不做项目运行看板。

每条显示：
方案名称、内容或作品类型、外部目标、修改时间和修订。
提供继续编辑、复制一份、导出等简洁入口。

状态使用：
草稿 / 材料已准备 / 已记录外部反馈。
用户采用可以另作个人选择记录，不等于专业效果已验证。
不出现渲染完成、成片已交付或生产任务运行中。

同一套列表展示三个样例：
桌面笔记产品的品牌与宣传方案；
原创小说片段的二维漫剧方向；
用户歌词的MV与声音方案。

这些是方案文档，不是三套制作软件。
选择任何方案均回到同一种D02工作页，内容和上下文正确对应。

用户可自愿附外部结果截图、链接、时间码或一句反馈。
不要求上传成品才能继续使用，也不自动同步到AAOS。

七、首轮不单独生成、但必须预留的详情

以下作为后续局部状态设计，不在本轮挤入四张主画面：

A. 参考分析与重构
缩略图或可读内容为主，依参考类型选择构图、色彩、信息层级、材质、镜头、节奏、叙事或声音维度。
用户标记想保留、想改变、仅作灵感。
分清实际观察、推断和用户补充。
反推提示词是根据参考组织可用描述，不是找回原始提示词。
只有链接时写“已保存链接，尚未解析”；关键帧不能代表分析了整段视频。

B. 外部目标适配与交接
分别选择软件或平台、模型及版本、任务模式、可选外部Agent。
允许暂不确定，不把它们混成一个型号下拉框。
依据目标入口支持情况，分配身份/形体、风格、运动、声音等参考角色。
提示正文、参数、参考材料和外部步骤分开。
已知不兼容解释原因；未知保持待确认，不发明参数。

C. 知识详情与编辑
正文优先，来源与适用范围简洁可查。
修改保存新修订，保留历史。
旧方案继续绑定原修订，不被知识更新悄悄改写。
保存失败保留草稿，不把保存动作变成专业验证。

D. 设置
方案助手服务、外部目标档案、来源与更新、数据与备份、专业接口与诊断。
专业接口和标准接口保留，普通用户页面不展示端口、Schema和能力矩阵。
本轮不设计AAOS连接和自动派发。

八、模型与工具角色必须分清

方案助手：
帮助整理、分析和写方案的可选模型服务，配置在设置。
未连接时仍能浏览知识、编辑模板与使用已有材料。

外部制作目标：
用户准备在哪个平台或软件中，用哪个媒体模型和模式制作。
目标选择决定材料适配，不表示DESIGN-LAB已连接或调用该模型。

可选外部Agent：
用户可将说明或脚本草案交给它操作外部软件。
不要求必选，不在本软件自动启动。

不锁死Codex、MiniMax或任何厂商。
白模与镜头预演路线可以作为一种配方：准备外部3D说明，再将预演与参考交给合适的生成工具。
这是设计与交接路线，不宣称已经完成跨软件绑定。

不要填写未经核实的“最新模型”、价格、免费额度和兼容能力。
资料未知时显示“尚未确认”，不要设计全平台最强排行榜。

九、专业材料要适配任务

专业不等于提示词越长越好。

图像材料明确主体、构图、层级、材质、光线和保留/修改要求。
视频材料明确镜头目的、动作、运动、时长和连续性。
3D与粒子材料明确形体、材质、相机、运动意图和外部实施条件。
音乐、配音、音效分别组织风格结构、表达方式、停顿发音、声源动作与空间。

模型不支持的负向提示、权重符号、参数和参考方式不能硬套。
精确文字、几何、逐帧同步等要求可以建议由外部原生工具处理，不保证生成模型精确执行。

短剧和漫剧可引用人物与场景资料；只分析已提供内容，不宣称读过整部小说。
说唱与MV可整理歌词结构、节拍与镜头节奏，但不伪装已经听过或分析过未读取的音轨。

十、复制、导出与用户选择

方案、脚本、分镜、提示词、参数和参考说明可以分别带走。
按内容提供文本、Markdown、分镜CSV或有依据的结构化格式，不把所有格式按钮同时铺在首屏。

主要操作叫：
复制材料 / 导出方案 / 保存方案。
不要叫自动执行、立即出片、启动Agent或一键发布。

材料已准备不等于已发送，生成脚本不等于运行脚本。
用户采用不等于系统验证通过。
普通查看、复制和下载不加审批、打分或长表单。

十一、必要状态与轻量化

后续状态复用同一组件：
首次使用、空结果、仅保存未解析、助手未连接、输入能力不支持、目标不兼容、保存失败、版本冲突。

一句原因加一个可继续的操作，避免满屏红字与技术错误码。
没有数据不补零，没有分析不写成功，没有外部结果不显示已完成制作。

缩略图优先，媒体点击预览，不自动播放声音和视频。
列表按需加载，长文分段，重型内容不默认挂载。
无持续动效，不写未经测量的CPU、内存或响应时间承诺。

十二、本轮实际交付清单

本轮必须实际输出四张独立画板：
D01 设计辅助需求入口；
D02 方案工作页，默认设计方向；
D03 知识与提示词库；
D04 我的方案。

四张沿用同一套外壳、组件与演示方案。
不得只交付D01，也不得只输出抽屉、设置页或规范海报。
不要把四张缩成一张总览代替独立画面。

本轮不要求代码、原型联调、真实模型调用或操作验证报告。
不自行声称“已接通API”“已分析附件”“已生成媒体”或“复制与导出已验证”。

在画板外简要注明每张的主要操作和去向。
若数量受当前工具限制，明确本次完成与尚缺画板，不以文字宣称全部完成。

十三、版本与设计约束

本轮四张形成新的DESIGN-LAB静态基线。
后续只针对指定画板修改，保留未修改画面，不把新改动变成整套重画。
相同方案、参考、知识条目与外部目标跨页面保持一致。

输出或同步DESIGN.md，内容与本提示词一致。
旧模板、随机补充文案和工具自动生成的说明不得重新定义产品。

不要把本提示词、技术架构、设计规范和验收条款画成用户界面里的说明卡片。

最终自查：
用户是否知道从哪里开始、会得到什么、去哪里实施？
设计知识与提示词的管理更新是否有清楚入口？
品牌、UI、3D、粒子、视频与音频是否共享结构而没有堆成重型软件？
方案助手、制作目标和可选Agent是否分清？
是否保留用户选择，且没有越界自动执行或假装交付成品？

# 二、我建议的开发方式

**不要另建三个新仓库。**

直接从三个项目各自的最新 `main` 创建独立 UI worktree/branch：

```text
ArcheAxis:
ui/aaos-commercial-frontend-20260930

WORK-LAB:
ui/worklab-commercial-frontend-20260930

DESIGN-LAB:
ui/designlab-commercial-frontend-20260930
```

这样做的好处是：

```text
当前 main / Authority
        │
        ├── UI 独立分支
        │      ├── IA
        │      ├── Design System
        │      ├── Components
        │      ├── Motion
        │      ├── Assets
        │      ├── Interaction
        │      ├── E2E
        │      └── Windows/Packaging
        │
        └── 原项目业务开发继续
                       │
                       ▼
                最终 rebase
                       │
                 UI Integration
                       │
                 PR → main
```

**前端分支可以运行、构建、打包、截图、做 UIA/E2E，但不重构项目业务 Authority。**

这是最重要的边界。

AI 模型、API 与额度：核验汇总

核验快照：2026-09-15。范围为本对话已报告项目，并补入 NVIDIA 与 Hugging Face 官方免费计划；不把补充建档称为今日新发布。精确来源见各段的来源编号及文末索引。

一、今日最重要变化

这次交付最重要的不是再增加“新模型”数量，而是把能够据以配置、预算、测试的事实与历史待核实数字分开。优先级按预算与项目价值排序，不按厂商排列。

低成本执行候选：DeepSeek V4.1-Flash、Gemini 3.8 Flash。 前者的正式调用别名是 deepseek-flash，旧Flash别名仍可能响应，但实际已转到新模型；V4-Pro则按后续官方通知继续提供服务。后者覆盖文本、图片、音频、视频与PDF输入，输出为文本；它不是原生图像或音频生成模型。[S10][S11][S07]

高难任务对照：GPT-6 Astra、Claude Fable 5.1。 保留为疑难代码、长任务和重要审计的对照候选，不预设高价必然更可靠。Astra超过272K输入会触发整次请求长上下文价。Fable新版本还涉及强制工具调用、思考块和编辑历史轮次的兼容性变化，不能只更换模型名称就宣称无缝迁移。[S01][S04]

执行框架候选：Agents API。 当前官方概览涵盖托管执行、会话、沙箱、上下文管理与恢复。它适合与 WORK-LAB 的既有能力作对照，但不是新的独立大模型，也不应成为重建三套任务系统的理由。[S03]

设计与学习专项：GPT-Image-2.5 Flare / Sunburst、GPT-Live-1。 图像模型纳入严格局部编辑测试；语音服务纳入学习者停顿、复述与指令确认测试。价格可查不等于项目效果已经通过验收。图像作品是否真正保持比例、字形、局部材质和透明通道，必须在交付前检测。[S02][S32]

三、顶级模型排名变化

可核验的独立快照来自 Artificial Analysis 2026-09-09报告：Intelligence Index中Astra与Fable 5.1均为53；对应设置下任务成本为3.26与7.63美元。Coding Agent Index中Astra/Codex与Fable/Claude Code均为62。它比较的是指定设置及执行框架，不是本包重新跑出的结果，也不是保证你的项目成本比恒定。[S29]

因此保留“两者作为高端对照”的结论，而不宣称所有最新榜单都已扫描、所有视觉或长任务指标都由同一模型领先。评测版本变更、推理强度、回退策略、执行框架与任务集必须随成绩保存。[S29][S30]

Bolt Build Index属于厂商自测；Kimi“接近K3”、DeepSeek发布图及GPT-Live历史效果数字，也不能直接升级成独立机构对你的项目验收。历史报告中的高精度适配分不是实测数据，本包统一降低这种表达的伪精确性。[S20][S11][S17]

ArcheAxis 继续保留人类学习与机器调用两侧。个人笔记、经验与假设允许先入库；外部核验状态决定如何展示和引用，而不是决定是否允许保存。模型输出必须能回溯原文、页码或时间戳，不能把自动“验证通过”当作来源。

WORK-LAB 负责模型适配、任务状态、权限、重试、预算、日志与恢复；本包不另建一套重复控制面。所有候选先注册为可回退的适配器，不能因榜单领先就改掉已有执行流程。

DESIGN-LAB 保留设计判断、可编辑中间结构、视觉验收和交付约束。图像模型只承担具体生成或编辑步骤；严格的尺寸、布局、文字和原图保持需要工具校验，不能依赖模型口头保证。

五、建议立即测试

先做“一个任务、两个候选、一个明确验收结果”，避免一次开启全部付费模型。

第一阶段：无需付费调用。 核对模型ID、账户额度、接口条款、地区和密钥隔离，关闭自动充值；选定同一批脱敏测试输入。预算上限未填写时，任务包默认阻止付费执行。

第二阶段：小样本对照。 ArcheAxis先比较DeepSeek与Gemini的原文锚点、表格提取和错误定位；WORK-LAB先比较同仓库同权限下的工具调用、跨文件修复和中断恢复；DESIGN-LAB比较Flare与Sunburst的非目标区域变化、比例保持和文字准确率。

第三阶段：对照审计。 仅把失败样例、证据冲突或疑难修复交给Astra/Fable。若低价方案通过验收，保留其执行角色；若失败，记录失败原因，而不是自动提高预算重试到成功。

第四阶段：决定是否替换。 至少经过独立复核、风险检查、成本统计与回退演练后，才允许从“测试”升级为“现有组件替换候选”。本包没有给任何候选生产批准。

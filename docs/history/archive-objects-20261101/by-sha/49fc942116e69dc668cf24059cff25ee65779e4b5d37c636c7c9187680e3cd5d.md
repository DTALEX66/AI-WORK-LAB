# Design System: AAOS 双系统前端 — 2026-10-30 R5

本文件仅规定本轮界面视觉与交互表达，不创建新的业务权威。用户已认可的彩色渐变、五入口与共享知识底座优先于通用设计模板。

## 1. Visual Theme & Atmosphere

本地个人知识桌面软件，深色石墨底、清晰玻璃外壳、彩色主题与真实内容封面。工作台适度丰富，阅读与作答区域安静；研究/资产工作区可提高密度。参考既有视觉的材质与颜色，修复层级和场景职责。允许对称和非对称布局，以任务清晰为准。

## 2. Color Palette & Roles

以下为本轮建议起始值，不宣称由截图精确采样；视觉与既有批准截图对齐后可微调。
- 深空画布 #0A0E13：应用背景。
- 基础表面 #10171F：正文与工作区。
- 工具表面 #17212C：工具栏与辅助区。
- 抬升表面 #202D3A：弹层与选中详情。
- 主要文字 #F2F6FA；次要文字 #B8C6D4；元信息 #8E9EAE。
- 边界 rgba(196,220,240,0.14)：轻分隔，不给所有边缘发光。
- 主要交互 #25CEE2：当前选择、主要行动、键盘焦点；小字使用明亮前景，保证可读。
- 青色摘要渐变 #087F96 → #23C4D7。
- 粉橙摘要渐变 #A52D8B → #F163A5 → #FFBF78。
- 翡翠摘要渐变 #087F73 → #15BE94 → #8DDB61。
- 蓝紫摘要渐变 #373180 → #296DCB → #17AFDE。
- 正常状态 #49D8AD；注意 #F1C15B；错误 #F27D88，配文字或图标。
暖色仅为已认可的卡片局部与语义反馈，整体背景保持冷中性。允许多色内容与渐变，不套用“最多一个色”“禁蓝紫”等通用限制。

## 3. Typography Rules

中文优先 PingFang SC、Microsoft YaHei、Noto Sans SC 和系统sans-serif；拉丁文字沿用项目现有可用字体。工程数值与代码使用项目现有等宽字体。无需为了字体切换工程依赖。
- 页面标题约24–28px，区块标题16–18px。
- 界面文字14–16px，阅读正文16–18px，正文行高约1.6–1.8。
- 常用说明不缩成满屏微型字。标题、正文、元信息通过字重、间距和颜色区分。
- 中文阅读行宽按实际字号与窗口验证，不机械套用英文字母字符数。
- 具体尺寸由后续本地Codex统一适配，本轮不因缩略图与画布比例反复返工。

## 4. Component Stylings

按钮：主要行动可用青色/青绿渐变，白色按钮可用于需要更强对比的位置；同一任务区域一个主要行动，次级操作使用轻背景、描边或更多菜单。
摘要卡：保留四张有色渐变卡，清晰标题、主数值或状态、短说明和明确去向。卡片不强制相同内容量。
资料与课程卡：使用独立封面、关键属性和继续位置，不将整张软件截图作为封面。
密集对象列表：名称、类型、状态和下一步优先；来源、范围与版本按需展开，避免无限卡片嵌套。
面板：约14–20px圆角；控件约8–12px圆角；间距基于4/8px。主内容可用简单分隔，不能每段都套卡片。
玻璃：用于Dock、全局壳、浮动面板与弹层；提供不透明降级。正文、长表格和输入区保持稳定底色。
输入：明确标签、焦点、错误与保存状态。中文IME输入不触发意外提交。
状态：功能接入/内容核验/人的掌握/AI资产资格分开，不共用一个百分比。候选、已采用、可用于当前任务与使用有效分别表达。
未来能力：可打开说明与示意；示意不能伪装实际运行，不能全部画成不可理解的禁用按钮。

## 5. Layout Principles

固定壳：顶部系统菜单、全局搜索与状态；场景内容区；底部五入口Dock；小栖与任务按需打开。
业务五入口：工作台 / 资料与知识 / 研究与比较 / 学习与表达 / AI助手。
资源、能力、设置、任务为共享工具，保留来源场景与返回位置。
层级：应用导航 → 当前任务与局部切换 → 当前操作 → 工作内容。移除重复的标题、标签行和研究工具栏。
学习任务：路线 / 当前活动 / 按需辅助；AI资产：对象列表 / 当前处理 / 按需依据和范围。比例依任务调整，可收起辅助区。
使用可适应布局、最小可读宽度与内部滚动；内容区随应用窗口延伸，避免在长画板中央固定一个矮编辑器。精确尺寸修复交本地Codex。
图谱、叠卡允许有目的的前后层次，禁止文字、点击区域或弹层意外遮挡。
常用点击目标约40–44px，窄窗优先收起辅助工具，键盘焦点可见；不因界面丰富牺牲可读性。
不另做移动端产品，本轮为桌面界面。

## 6. Motion & Interaction

普通切换约120–240ms，面板进入可约180–280ms；允许轻弹簧，避免列表逐项等待造成延迟。
星核可低频轻微呼吸，选中和扇出有稳定对象身份；正文、输入、按钮不无限循环。
优先transform/opacity，不持续驱动大面积模糊。图谱隐藏/离屏停止绘制，支持暂停、减少动态与列表替代。
保留选区、焦点、草稿、滚动、局部图谱视口；关闭面板不等于取消工作，恢复布局不重发任务。
全局导航、图谱选择、详情对象和任务状态分别管理；不要用hover替代明确打开动作。
静态图说明意图即可，未经运行不承诺性能或真实交互完成。

## 7. Anti-Patterns

- 不恢复禁青蓝、白色主按钮唯一、整页灰卡等过时限制。
- 不让所有功能、页面、卡片持续发光或循环动画。
- 不使用营销Hero、巨型口号、满屏双语小字或工程HUD填充。
- 不机械复制S05研究的编号、工具栏与Dock选中项。
- 不把学习等同做题，把AI学习等同聊天，把空间图谱等同记忆宫殿。
- 不把课程完成、事实可信、人的掌握和AI资产评测混成同一状态。
- 不强制所有任务联网、研究核验、评审通过后才能保存笔记。
- 不绘制企业团队管理、第二份知识库或全Agent原始会话中枢。
- 不把开源候选、前端示意或截图当作真实接入证据。
- 不以“更多”代替186项的覆盖索引；也不把186项全铺到首页。



## 8. 本轮活动与科研扩展
既有工作台/人类学习概览/AI资产概览保留，本批增加L1学习、L2仿真、L3空间记忆、A1纠正候选、R1科研计划五个工作区。参考效果图使用同一壳；不把研究或学习表格复制成全局通用页面。
未来能力可设计完整预览，清楚标待开发/待核验；预览状态与真实任务隔离。优先当前活动，候选接入方式、难度和依赖在能力详情呈现。
文字契约优先解释状态和权限，图片是构图参考。尺寸精修交本地Codex，不反复重做概览。

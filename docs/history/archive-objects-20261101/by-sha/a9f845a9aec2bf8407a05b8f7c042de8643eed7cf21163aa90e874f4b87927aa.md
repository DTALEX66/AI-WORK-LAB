# 七、语言规则：现在已经基本稳定，不应再重新讨论

| 层 | 正式语言/框架 | 权限 |

**禁止 live sync 两套数据库。**

- Python 主后端；

都应直接由 authority gate 拒绝，而不是重新讨论。

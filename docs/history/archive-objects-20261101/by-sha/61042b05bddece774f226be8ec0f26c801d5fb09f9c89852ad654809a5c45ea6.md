# 观猹项目对三个项目的增强与融合评估

调研日期：2026 年 10 月 13 日。对象：星环知识系统 ArcheAxis Knowledge、WORK-LAB、DESIGN-LAB；同时评估星栖 ASTRYN 在星环内的角色化交互。

最值得吸收的是明确的能力增量：设计修改意见可定位、AI 交付物可找回、记忆过期与冲突可诊断、视频工程可继续编辑、品牌图形可输出矢量、学习过程可展示错因。它们可以落在现有模块内。新的完整知识平台、Agent OS、模型管理中心和无限画布，通常会造成重复。

## 调研范围与判读

读取观猹公开产品目录的 30 页，共返回 2,932 个不同记录 ID；读取 15 个分类和 72 条候选详情。目录中的 OpenViking 有两个 slug，合并后本报告列出 71 个候选。记录数是本轮读取快照，不是网站保证的全部库存，也不表示 2,932 个项目都完成了源码审计。

候选详情用于识别功能与官方入口；重点候选进一步读取了官方 README、官网或文档。下表逐项是适配评估，不是安装完成或生产可用声明。尚未确认的 API、许可与维护状态不作肯定承诺。本轮没有修改三个项目、安装外部组件或运行真实生产评测。

项目职责以当前仓库文件优先：星环正式方向是 Tauri 2、React/TypeScript/Vite 与 Rust Core 单写者 SQLite/CAS，Python workers 隔离；OSUI 和 Avalonia 历史稿不作为本轮界面实施依据。WORK-LAB 是客户端中立的规范配置与治理层，Observer 只读。DESIGN-LAB 是专业设计判断、生产与交付能力层，专业编辑在宿主中进行。星栖当前是 AAOS 原生角色化交互与陪伴子系统，独立开发宿主用于验证，不是第二个正式前端。

## 当前最值得优先处理的补强

| 优先事项 | 对照候选 | 建议落点 | 对用户的实际变化 | 当前做法 |
| --- | --- | --- | --- | --- |

## 重点候选的边界

**EditHere** 提供截图批注、元素移动坐标、视频时间点反馈和 JSON/CLI 交接。其原创软件采用 PolyForm Noncommercial，是源码可用许可；个人非商业研究与商业开发使用场景不能混为一谈，商业使用、销售产品内置或收费服务需按上游许可获得授权。当前可以优先参考需求表达方式，商业代码吸收不能预设许可。它本身不提供模型调用或额度。

**IntentKit** 把日常设计表达整理成术语、效果预览、参数与 JSON。这与 DESIGN-LAB 的专业 Brief 很贴近，适合作为意图输入的体验参考。AI 解析和站点免费访问不等于它是通用模型入口，也不证明源码可自由再分发。

**Sesame** 的独特价值是找回 Agent 产物，补足“任务完成以后东西在哪里”的体验。官方为 MIT、macOS 13+。用户当前 Windows 环境不能直接按 Mac 客户端可用来规划；可以从现有回执生成标题、项目、日期、文件路径和版本的只读投影。WORK-LAB 维护产物索引和任务关系，星环仅通过已有授权入口接收选定知识或资产记录。

**Minta** 将记忆的过期、矛盾、重复与碎片化作为诊断对象，开放核心为 Apache-2.0，高级资产有独立边界。和你现有治理目标存在重叠，真正要比较的是检测机制与用户处理流程。模型判断应先成为发现项，由记录所属系统处理；不能由第三方诊断器直接写星环或 WORK-LAB 的规范数据。

**gtrk CLI** 适合粗剪、字幕、配画面和可编辑工程交付；CLI 为 MIT，但调用同合云功能需要账户和额度，桌面客户端与云端服务不是随 CLI 一并变成自由组件。官方给出 Windows 客户端与可精修工程路线，仍须用你的素材实际打开、修改、导出后才证明适用。

**OpenStoryline** 为 Apache-2.0 视频剪辑 Agent，提供 MCP、CLI 和可复用 Style Skills。适合在 DESIGN-LAB 接入具体视频工具能力，WORK-LAB 管理声明与执行回执。可复用剪辑风格对三个项目的系列宣传片有价值，但官方视频、字体和音乐不能凭代码许可就默认具有相同素材权利。gtrk 与 OpenStoryline 在粗剪任务上重叠，不建议同时建设两条完整生产主线。

**QuiverAI** 官方提供 Text to SVG、Image to SVG 等 API，属于可接入服务候选。可用于三个品牌的图标、线条标志和插画探索。生成矢量仍要检查节点结构、路径可编辑性、文字转曲、字体、比例与宿主读回，不能由“SVG 文件存在”推断专业交付完成。官网部分字体能力仍标注 Coming soon，不能按观猹旧介绍写成全部已实现。

**OpenMAIC** 提供文档到互动课程、测验、白板和 HTML 仿真等能力，当前代码主线为 MIT；1.2 方向已转到服务器与 PostgreSQL，显著比一个前端组件重。未来可把课程输出接入星环学习资产与受限呈现容器，学习状态继续归星环；不吸收整套教师同学 Agent runtime、第二模型设置或第二课程主库。当前先评估一次“已选材料→课程→答题记录”的有界流程。

**Crawl4AI、DeepTutor、AIRI** 都有你仓库中的既往研究记录。Crawl4AI 与 DeepTutor 出现在星环历史冻结矩阵中，这只证明早有研究，不能证明当前版本完成；AIRI 在星栖 2026-10-12 矩阵里明确列为包级 adapt。这三项属于继续收口或升级对照，不算新发现。

**OpenViking** 的目录范围检索、L0/L1/L2 摘要分层与可检查的上下文路径有研究价值。当前官方主项目为 AGPLv3，CLI 与 examples 另有 Apache/MIT 分区，不能沿用旧许可记忆。整套引入会同时覆盖知识、长期记忆和技能管理，与星环和 WORK-LAB 重叠；可以比较检索机制或外置实验，不预设可内嵌、可闭源或数据库替换。

**OneCLI** 在观猹中仍以凭据安全工具呈现，但官方已发展成团队 Agent harness。最小增量是只按权限注入凭据的网关；整套团队 runtime 超出 WORK-LAB 定位。核心 Apache-2.0 与 ee 企业授权路径需分开。凭据注入代理也需要检查客户端订阅和网络协议兼容性，不能把订阅凭据变成通用 API Key。

## 前端应补充的入口建议

以下是现有页面内部的建议入口，不是另起一级菜单或新增整套前端。

| 项目 | 应展示的能力 | 具体内容 |
| --- | --- | --- |
| 星环 | 资料收集和处理 | 来源、原件、处理结果、片段与时间点、失败和重新处理 |
| 星环 | 知识治理和学习 | 冲突依据、版本、学习路径、错因待确认、复习与掌握反馈 |
| WORK-LAB | 模型和连接管理 | 当前客户端、合法 API 或客户端订阅来源、本地端点、能力、测试连接、故障与用量来源 |
| WORK-LAB | Skills 和 MCP | 规范版本、来源、投影到哪个客户端、差异、检测结果与回滚 |
| WORK-LAB | Observer | 运行、等待输入、失败、完成、产物链接和已校验回执；操作经独立命令入口 |
| DESIGN-LAB | Brief 和反馈 | 设计表达、参考、效果参数、修改区域、改动前后及视觉验收 |
| DESIGN-LAB | 交付 | 源文件、SVG、剪辑工程、最终成片、依赖、rights、宿主读回结果 |
| 星栖 | 同一宿主内的角色呈现 | 侧栏、嵌入或浮窗模式；角色档案、专注时的提醒节奏、语音开关 |

WORK-LAB 的共享路由只负责它获准管理的客户端与工程工作流。星环独立使用自己的宿主模型端口，DESIGN-LAB 保持平台中立；二者可导入授权配置投影，但不能变成必须依赖 WORK-LAB 才能启动。API、应用订阅与本地服务三种来源应分开显示可用能力，订阅不自动等于提供 API。小栖从星环的宿主端口使用模型，不另设模型中心。

## 能力共用与冲突处置

- 知识内容、学习记录与可信治理归星环；工程配置、规则投影与任务回执归 WORK-LAB；设计项目与宿主产物归 DESIGN-LAB；角色人格、互动与呈现归星栖。项目仍保持独立业务存储。
- 共用通过有版本的 Adapter、资产 URI、hash 与回执进行。外部组件只能操作其获得的输入输出边界，不能直写另一个项目的主数据库。
- 生成内容可以先保存与使用；保存不等于成为已验证知识。第三方诊断发现、模型评分、课程内容和角色记忆修订各有对应治理流程。
- 同类候选只做同输入对照：搜索从博查、Exa、Parallel 中收敛；粗剪从 gtrk、OpenStoryline 中收敛；3D 从 Meshy、Tripo、Hitem3D 中收敛。它们可以有不同特长，但不应默认全部安装。
- Observer 保持只读。提醒、暂停、恢复、发任务等动作由正式控制入口发出，再回到 Observer 展示真实回执。
- 当前收敛页面与最短用户旅程；随后补一个组件的真实闭环；重型课堂、3D、常驻情境感知与自主陪伴放在未来，不提前宣传为已支持。

## 可复跑的最小评估建议

| 能力 | 同一输入 | 通过条件 |
| --- | --- | --- |
| 界面反馈 | 一张真实界面、五处修改 | 区域与版本正确、五项意图均保留，修改后逐项读回 |
| 产物找回 | 多个项目的授权产物记录 | 找到目标与正确版本，坏路径有明确状态，不暴露未经授权正文 |
| 记忆诊断 | 当前与旧规则、已撤销决定、重复记录 | 区分过期与冲突，保留来源；不误删现行规则 |
| 视频交付 | 同一广告片素材、字幕和分镜 | 工程能在目标宿主打开，修改字幕与镜头后能重新输出 |
| SVG | 同一品牌 Brief 和参考标志 | 路径可编辑、比例正确、字体和第三方元素有记录；宿主打开读回 |
| 学习增强 | 同一份资料和用户答题记录 | 课程可回到来源片段；错因可纠正，复习状态进原有学习合同 |
| 搜索 | 同一组中文与专业查询 | 来源质量、正文可取得、去重、耗时与成本都有可比较记录 |

## 1. 项目定位

**PhET Density / 密度** 是科罗拉多大学 Boulder 的 PhET 互动仿真实验，核心围绕：

- 质量 Mass
- 体积 Volume
- 密度 Density
- 浮沉现象
- 阿基米德原理 / 排开液体思想

PhET 官方介绍其仿真为免费、互动、基于研究的科学与数学模拟，并强调通过学生访谈和课堂观察进行测试；HTML5 仿真可在线运行，也可下载使用。citeturn774628view2

## 3. 功能结构

这个仿真不是单页小游戏，而是分成 **3 个教学屏幕**：Intro、Compare、Mystery。源码配置里明确列出了这三个 screenNameKeys。citeturn984174view0

### Intro｜入门探索

用于让学生直接拖动不同材质方块到水中，观察浮沉。核心逻辑是：调节质量、体积或自定义材料后，观察密度变化以及是否浮起/下沉。官方模型说明里提到，Intro 会提供固定材料与 Custom 自定义选项，学生可以通过质量、体积、密度显示理解浮沉关系。citeturn696937view0

### Compare｜对比实验

这个部分适合做“控制变量”教学：相同质量、相同体积、相同密度下，不同物体表现如何。模型说明提到 Compare 屏幕用于比较相同质量、体积或密度的方块，并通过滑块观察浮沉变化。citeturn696937view0

### Mystery｜神秘物体推理

这是最有教学价值的一屏。学生需要通过测量质量、体积，推断密度，再对照密度表判断未知物体材质。模型说明中提到 Mystery 屏幕有固定集合、随机集合、密度表，并用于识别未知材料。citeturn696937view0

## 5. 教学设计价值

这个仿真强的地方不是公式本身，而是它把抽象概念变成“可操作变量”。

PhET 官方研究页强调，其设计原则来自学习研究和仿真访谈；每个仿真通常会进行 4–6 次 think-aloud 学生访谈，用来观察学生如何与仿真交互和学习。citeturn774628view3

它的教学优势主要有：

| 设计点 | 教学价值 |
|---|---|
| 拖动物体进水 | 让浮沉从文字概念变成直观现象 |
| 质量 / 体积 / 密度联动 | 帮学生理解“密度不是质量本身” |
| 同质量 / 同体积 / 同密度对比 | 很适合讲控制变量 |
| 神秘物体模式 | 把计算变成推理任务，学习动机更强 |
| 密度表 | 引导学生从观察走向证据判断 |
| 即时反馈 | 调整变量后立刻看到结果，适合探究式学习 |

## 7. 对你有价值的借鉴点

如果你是想研究它的产品/课程设计，我建议重点看 **Mystery 模式**。它不是单纯展示密度公式，而是设计成“测量 → 推理 → 验证”的学习闭环。

可借鉴结构：

1. **先给现象**：物体为什么浮/沉？  
2. **再给变量**：质量、体积、密度可以调。  
3. **再做对比**：同质量、同体积、同密度分别观察。  
4. **最后做任务**：给未知物体，让学生用数据判断材质。  

这套结构非常适合改造成：

- 初中物理密度互动课件
- 小程序物理实验
- AI 教学 Agent 的交互实验模块
- Obsidian 知识库里的“可交互实验笔记”
- 课堂练习题生成器
- 学生探究式学习任务单

## 8. 我的结论

这个 PhET《密度》仿真是一个很成熟的 **低门槛、高反馈、探究式物理学习案例**。它最值得借鉴的不是页面视觉，而是教学结构：**用交互现象引出概念，用变量控制建立理解，用神秘物体任务完成知识迁移**。

如果你要复刻或做类似项目，我建议不要一开始照搬它的完整 3D/物理引擎结构，而是先做一个轻量版本：

**第一版核心功能：水槽 + 方块 + 质量滑块 + 体积滑块 + 密度显示 + 浮沉判断 + 神秘物体挑战。**

这样就能保留它最核心的教学价值，同时开发成本低很多。

## 三、我的判断：最值得你研究的 5 个

**第一优先级：PhET Buoyancy + density-buoyancy-common**  
这是最接近你给的 PhET Density 的项目，属于同一套“密度/浮力”仿真体系。缺点是工程复杂，PhET 自己的 SceneryStack、构建流程、依赖体系比较重，不适合新手直接复刻。PhET 官方开发文档也说明它们用 SceneryStack 开发 HTML5 教育仿真。citeturn855065view6

**第二优先级：oPhysics Buoyancy / Density Lab**  
它比 PhET 简单很多，但教学目标很清楚：滑块控制变量、观察浮沉、计算密度、输入答案验证。你要做轻量版，先对标它更现实。citeturn490397view1turn490397view2

**第三优先级：ExploreLearning Gizmos Density**  
它的课程包装比技术更值得看：学生任务单、教师指南、评估题、词汇表、订阅权限设计都很成熟。适合你研究“怎么把一个仿真变成可销售/可教学的课程产品”。citeturn855065view1

**第四优先级：Open Source Physics Singapore**  
它适合研究“开源教育资源 + 可嵌入网页 + 多仿真集合”的模式，尤其适合以后做 Obsidian、飞书、网页课件、小程序嵌入。citeturn490397view4

**第五优先级：SimPop / Javalab**  
这两个适合看极简交互。不要一开始追 PhET 那种完整体系，先做“方块 + 水槽 + 密度滑块 + 浮沉判断”就能跑通。citeturn490397view5turn490397view6

---

## 四、如果你要自己做，我建议的复刻方向

不要直接照搬 PhET。更好的路线是：

**第一版：轻量 2D 教学实验**

核心功能：

- 一个水槽
- 一个或多个方块
- 质量滑块
- 体积滑块
- 物体密度显示
- 液体密度滑块
- 浮 / 沉 / 悬浮判断
- 简单实验记录表

**第二版：任务关卡**

加入：

- 神秘物体
- 随机材料
- 让学生测质量、测体积、算密度
- 判断材质
- 自动生成实验报告

**第三版：AI 教学版**

加入：

- AI 提问：“为什么它浮起来？”
- 自动判断学生答案
- 给出提示而不是直接给答案
- 生成错题卡片
- 导出到 Obsidian / 飞书 / PDF

## 五、结论

有同类项目，而且可以直接分成两条借鉴路线：

**想做教学产品：看 PhET、Gizmos、CK-12、PBS、Concord。**  
**想做开源代码实现：看 PhET 源码、Open Source Physics Singapore、harshit23897/Buoyancy、threejs-water。**

真正落地的话，我建议你不要从 PhET 源码硬啃开始，而是先用 **oPhysics + SimPop 的轻量逻辑** 做 MVP，再逐步吸收 **PhET 的模型结构** 和 **Gizmos 的课程包装**。
